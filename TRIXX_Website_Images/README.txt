How to use
----------
1. Each JPG has a matching TXT file with its intended website placement.
2. TRIXX_visual_board_full.png is the original generated visual board.
3. Images are concept crops from that board. They are useful for prototypes, layout planning,
   and early website mockups, but they are not separate full-resolution photo generations.
4. For production, generate each image separately at the recommended dimensions in the prompt guide,
   especially the homepage hero and vertical architectural collection images.
5. Keep headings, navigation, labels, and buttons as live HTML text; don't bake text into final imagery.
6. Compress production images to WebP/AVIF where supported.
7. Don't present AI-generated imagery as real completed projects, real customers, or actual school/farm sites.
